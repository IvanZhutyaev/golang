## Указатели
**Указатели представляют собой объекты, значением которых служат адреса других объектов. Через указатель мы можем обращаться к адресу переменной. Указатели, как и любые другие объекты, имеют определённый тип**
```go
var x int =4 //определение переменной
var p *int //определение указателя
p=&x //указатель получает адрес переменной
fmt.Println(p) //значение самого указателя-адрес переменной x
fmt.Println(*p) //значение переменной x
```
**Операция * называется разыменование<br>Экономия памяти<br>Через указатель можно изменить значения**
### По умолчанию, если указателю ничего не присвоено, то он имеет значение nil(null)

## Функция new
**Язык Go также позволяет создавать безымянные объекты - они также размещаются в памяти, но не имеют имени как переменные. Для этого применяется функция new(type)**
```go
p:=new(int)
fmt.Println("Value:",*p) //Value: 0 -значение по умолчанию
*p=8
fmt.Println("Value:",*p) //Value: 8
```
**Указатели на указатели существуют!<br>Бывают массивы указателей<br>Указатели могут выступать в качестве параметров функции**
```go
d := 5
var p *int
p = &d
fmt.Println("Before:", d) //5
changeValue(p)
fmt.Println("After:", d) //25

func changeValue(x *int) {
    *x = (*x) * (*x)
}
```
***int - тип указателя**<br>
***x - разыменовывание указателя для присваивания значения в ячейку памяти**<br>
**&d - получаем адрес переменной для присваивания в указатель**

## Структуры
**Представляют составной тип данных, определяемый разработчиком и служащий для представления какких-либо объектов**
```go
//Example
type person struct{
	name string
	age int
}
//Можно записывать как вне функции, так и в функции
func main(){
	var tom person = person{"tom", 23}
	fmt.Println(tom)
}
```
### Структуры как поля других структур
 - Вложенные структуры(nested struct) определяются как именованные поля внутри другой структуры, и доступ к их полям осуществляется с использованимем имени поля внешней стркутуры
 - Встроенные структуры(embedded struct) определяются ьез имени поля, что продвигает их поля во внешнюю структуру для прямого доступа. Предлагают более чистый синтаксис, но могут вызывать конфликты имён

 ## Методы
 ```go
 // Создание структуры
 type person struct{
	name string
	age int
 }
 // Первая скобка - к какой структуре относится, дальше параметр и возвращаемое значение(см.в.)
 func (p person) speak(word string) string{
	return p.name + " says "+ word
 }
 // Вызов метода
 func main() {
	tom:=person{"tom", 20}
	fmt.Println(tom.speak("i am tom"))
 }
 ```
**При вызове метода, объект структуры, для которого определён метод, передается в него по значению. Однако такое поведение может быть нежелательным. Что если мы всё-таки хотим таким образом изменять состояние структуры:**
```go
func (p *person) update_age(new age int){ //Передаём принадлежность как указатель
	p.age = new_age
}
func main(){
	var tom = person("Tom", 24)
	var p_tom *person = &tom
	p_tom.update_age(33)
}
```
